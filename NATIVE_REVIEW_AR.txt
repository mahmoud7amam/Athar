- عدم طلب إذن الشاشة الكاملة إلا عند تشغيل الأذان أو تذكير الصلاة.
- إكمال عرض مجموعات dbAzkar وduaKhatm مع subSupplications في شاشة الأدعية.
- استخدام MediaPlayer.prepareAsync وعدم تغيير مستوى صوت المنبه العام للهاتف.
- فحص أسرار التوقيع في GitHub Actions قبل بناء Release والتحقق من ملف keystore والـ alias.
- إضافة تحقق SHA-256 لتوزيعة Gradle 8.11.1.

ما لم يتم التحقق منه
--------------------
- لم يتم بناء APK/AAB: بيئة المراجعة لا تحتوي Android SDK أو Gradle CLI.
- لم يتم تشغيل التطبيق على هاتف فعلي أو إجراء اختبار Play Console.
- النسخة الأصلية لم تصل بعد إلى التطابق الكامل مع الموقع: صفحة/أدوات القارئ المتقدمة والعلامات والتنزيلات وبعض إعدادات التخزين والتعليم تحتاج نقلًا، وشاشة الإقامة تحتاج مطابقة وظيفية وبصرية أكثر.
- القرآن والتفسير والصوت ومواقيت الصلاة عند أول تحديث تعتمد على الإنترنت.
- صلاحية Full-screen intent على Android 14+ ليست مضمونة؛ أهلية التطبيق وإقرار Play Console يلزم مراجعتهما قبل النشر.
- Gradle Wrapper التنفيذي (jar/scripts) غير موجود بعد. GitHub Actions يثبت Gradle مباشرة، أما البناء المحلي المعتاد فيحتاج إضافة الـ Wrapper الرسمي أولًا.

لا يُعَد هذا المشروع APK نهائيًا أو جاهزًا للنشر قبل حل البنود أعلاه واختبار Release موقّع على جهاز حقيقي.
