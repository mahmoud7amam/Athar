Athar — Performance pass + swipe-to-switch bottom bar + Vercel build fix
=====================================================

Bottom bar finger-scrub (js/ui/navigation.js -> initNavScrub, css/perf.css)
---------------------------------------------------------------------------
- Put a finger on any tab and slide left/right: the tab under the finger is highlighted live (tiny haptic tick).
- Stop on a tab for ~140ms and it opens; lift the finger and it opens immediately. A plain tap works as before.
- Tune with SCRUB_DWELL_MS / SCRUB_MOVE_PX at the bottom of navigation.js.

Performance
-----------
- Removed backdrop-filter blur from every card/list/reading-area (hundreds of elements re-blurred each scroll frame).
  Glass is now only on the header, bottom bar and transient overlays; blur radius lowered 24px -> 12px.
- Weak devices (<=4 cores / <=4GB RAM / data-saver) get class "lite" on <html>: no blur at all (see index.html head + perf.css).
- content-visibility on cards/settings sections so off-screen items are not laid out or painted.
- One unified 1s ticker: pauses completely while the app is hidden and updates only the visible clock page.
  The exact adhan scheduler handles prayer alerts without a redundant per-second scan; hadith reminders are checked once a minute.
- Firebase (~300KB) now loads dynamically after the first paint (firebaseReady promise) instead of blocking startup.
  Service-worker registration and admin tracking also wait for idle time.
- Tafsir and dua lists are pre-rendered while idle, so the first visit is instant.
- nav(): stopAudio() only when audio is actually open; storage stats (cache key counting) deferred + throttled.
- Splash: full ~11s greeting only on the first open of each day, then a ~1.6s quick splash.
  Set ALWAYS_FULL = true in the splash script of index.html to restore the old behaviour.
- Service worker shell cache is updated to athar-v17 so the new merged CSS/JS assets are fetched after deployment.
  The page uses cached-first navigation and refreshes the cached HTML in the background.
  NOTE: updates now reach users on the *next* launch after they are deployed.
- touch-action: manipulation (no 300ms tap delay), lighter transitions, short opacity fade between pages.

Vercel build fix
----------------
- The previous build check falsely rejected a comment containing a source JS path. It now validates actual src/href resource tags only.
- JavaScript whitespace/syntax are minified while public function names are preserved for inline HTML handlers.
- Service worker shell cache bumped to athar-v17 so the deployed bundle refreshes.

Deploy: web-only change (the APK is a TWA that loads the Vercel site) — web deployment does not require a new APK unless native Android code/permissions changed.

Athar — Native Voice Confirmation + Performance + Auto-dismiss
===============================================================

Native APK prayer confirmation
------------------------------
- The Android APK requests RECORD_AUDIO only after the user enables the prayer reminder.
- The native AdhanActivity displays the prayer-specific spoken phrase after the adhan ends.
- The user starts speech recognition with an explicit tap; it checks for the oath and the correct prayer name.
- Successful recognition records a local self-attestation timestamp and clears that prayer reminder.
- The app does not save an audio file or listen continuously in the background. Android's speech-recognition
  provider may process speech for transcription and may require network/service availability.
- The microphone cannot prove that a prayer was physically performed; this is a personal self-attestation.
- The reminder can run even when adhan sound is switched off. In that case it opens silently.
- If voice permission or an Android recognition service is unavailable, the app does not mark the prayer
  complete; the user can grant permission/retry or snooze the reminder.

Adhan screen timing
-------------------
- The regular native adhan screen automatically closes five seconds after playback finishes.
- When prayer reminder is enabled, the adhan visuals are replaced after five seconds by the centered
  voice-confirmation card. The card remains until the user confirms by voice or postpones it.
- The web fallback follows the same five-second close/transition behavior.

Performance changes
-------------------
- Removed the unrequested automatic 114-surah download at startup; full offline download remains available
  from the Quran page button.
- Quran page navigation now renders 60 pages at a time instead of all 604 at once.
- Cached iqama target calculations to avoid repeated local-storage JSON parsing every second.
- Optimized current-ayah lookup during reader scrolling.
- Deferred ordered JS loading so files download in parallel without changing execution order.
- Removed a duplicate Google Fonts stylesheet and reduced mobile glass blur intensity.
- Updated the service-worker cache version and added the glass stylesheet to the offline asset list.

Build/deployment
----------------
- Android version incremented to versionCode 15 / versionName 2.4.0.
- This archive contains modified project source; it is not a signed or newly built APK.
- The project is a Trusted Web Activity that loads https://athar-silk.vercel.app/?twa=1.
  Deploy the updated web project to that origin, then build and sign a new APK from android/.
